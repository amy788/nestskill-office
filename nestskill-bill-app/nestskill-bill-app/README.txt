NestSkill Bill App - build steps
1. Create a new (private) repository on github.com.
2. Upload ALL files from this folder, including the hidden .github folder.
3. Open the Actions tab > "Build APK" > wait ~5 min (it also runs on every push).
4. Open the finished run, download the "NestSkill-Bill-APK" artifact, unzip it.
5. Copy app-debug.apk to the phone and install it (allow "Install unknown apps").
To change the app later, edit www/index.html and push again.
